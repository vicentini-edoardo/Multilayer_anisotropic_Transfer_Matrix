# Contributing

Issues and pull requests are welcome.

1. Open an issue describing the bug or feature (include a minimal stack and parameters for numerical problems).
2. Fork, branch from `main`, and install with `python -m pip install -e . pytest`.
3. Add or update tests; `python -m pytest -q` must pass.
4. Update docs and [`CHANGELOG.md`](CHANGELOG.md) for user-visible changes.
5. Open a pull request.

See [`docs/development.md`](docs/development.md) for the code layout and conventions.
